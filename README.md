# Multivariate Statistics Course

Repository for notes, activities, and explorations in Multivariate Statistics.

## Project Structure

- **`notebooks/`**: Literate programming using Jupyter Notebooks (Python, SymPy).
- **`notes/`**: LaTeX source files for formal theory and reports.
- **`data/`**: Datasets (CSV, Excel, Statistica files).
- **`assignments/`**: Course activities and homework, organized by topic or date.
- **`statistica/`**: Tibco Statistica project files and exported results.
- **`src/`**: Reusable Python scripts and helper modules.
- **`docs/`**: Generated reports and references.

## Setup

1. **Python Environment**:
   It is recommended to use a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Tools**:
   - **Jupyter Lab/Notebook**: For interactive data analysis.
   - **SymPy**: For symbolic mathematics.
   - **LaTeX**: For high-quality mathematical typesetting.
   - **Tibco Statistica**: For specialized multivariate analysis.

## Literate Programming Strategy

We use Jupyter Notebooks to combine code, mathematical notation (via LaTeX in Markdown), and symbolic manipulation (via SymPy).
