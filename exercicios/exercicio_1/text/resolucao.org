* Exercício 1: Análise de Dados Binários
Considere a Tabela 1 com valores de presença-ausência de 8 espécies.

** Objetivo: Gerar dendrogramas utilizando os coeficientes de Sorensen-Dice e Simple Matching.

** 1.1 Carga de Dados
Utilizamos o script =ex1_1_read_data_from_csv.py= para carregar os dados.

#+name: ex1-carga
#+begin_src python :session multivariada :results output
import ex1_1_read_data_from_csv
df_bin = ex1_1_read_data_from_csv.read_data()
print("Dados da Tabela 1 carregados:")
print(df_bin.head())
#+end_src

** 1.2 Agrupamento Hierárquico
Utilizamos o script =ex1_2_clustering_binario.py= para calcular as matrizes de distância e plotar os dendrogramas.

#+name: ex1-clustering
#+begin_src python :session multivariada :results output
import ex1_2_clustering_binario
from scipy.spatial.distance import squareform

X = df_bin.iloc[:, 1:].values
labels = df_bin.iloc[:, 0].values

# Cálculo das distâncias
dist_dice = ex1_2_clustering_binario.calcular_matriz_distancias(X, metric='dice')
dist_sm = ex1_2_clustering_binario.calcular_matriz_distancias(X, metric='matching')

# Geração dos gráficos
ex1_2_clustering_binario.plot_dendrogram(dist_dice, labels, 'dice', 'Dendrograma - Sorensen-Dice', 'dendrograma_sorensen_dice.png')
ex1_2_clustering_binario.plot_dendrogram(dist_sm, labels, 'matching', 'Dendrograma - Simple Matching', 'dendrograma_simple_matching.png')
#+end_src
