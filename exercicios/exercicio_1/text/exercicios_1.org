** 1a. Dendrograma — Coeficiente Sorensen–Dice

O coeficiente de similaridade Sorensen–Dice considera apenas co-presenças:

$$S_{SD} = \frac{2a}{2a + b + c}$$

onde $a$ = co-presenças, $b$ = presença só na sp. 1, $c$ = presença só na sp. 2.
A distância correspondente é $d_{SD} = 1 - S_{SD}$.

*** Matriz de Distâncias

#+begin_src python :session ex1 :results output :exports both
# scipy.spatial.distance.dice(u,v) = (b+c)/(2a+b+c) = 1 - S_SD  ✓
dist_dice    = pdist(data, metric='dice')
dist_dice_sq = squareform(dist_dice)

df_dice = pd.DataFrame(np.round(dist_dice_sq, 4), index=species, columns=species)
print("Matriz de Distâncias Sorensen–Dice  (d_SD = 1 − S_SD):")
print(df_dice.to_string())
#+end_src

*** Dendrograma

#+begin_src python :session ex1 :results file graphics :exports both :file figures/dendrograma_sorensen_dice.png
Z_dice = linkage(dist_dice, method='ward')

fig, ax = plt.subplots(figsize=(10, 6))
dendrogram(
    Z_dice,
    labels=species,
    ax=ax,
    color_threshold=0.7 * max(Z_dice[:, 2]),

)

plt.tight_layout()

plt.close()

** 1b. Dendrograma — Coeficiente Simple Matching

O coeficiente Simple Matching considera co-presenças *e* co-ausências:

$$S_{SM} = \frac{a + d}{a + b + c + d} = \frac{a + d}{n}$$

onde $d$ = co-ausências e $n$ = total de locais.
A distância é $d_{SM} = 1 - S_{SM}$.

*** Matriz de Distâncias

#+begin_src python :session ex1 :results output :exports both
# scipy.spatial.distance.hamming(u,v) = (b+c)/n = 1 - S_SM  ✓
dist_sm    = pdist(data, metric='hamming')
dist_sm_sq = squareform(dist_sm)

df_sm = pd.DataFrame(np.round(dist_sm_sq, 4), index=species, columns=species)
print("Matriz de Distâncias Simple Matching  (d_SM = 1 − S_SM):")
print(df_sm.to_string())
#+end_src

*** Dendrograma

#+begin_src python :session ex1 :results file graphics :exports both :file figures/dendrograma_simple_matching.png

** 2c. MANOVA

Testamos se os vetores de médias das variáveis morfométricas diferem entre as espécies:

- $H_0$: $\boldsymbol{\mu}_{SETOSA} = \boldsymbol{\mu}_{VIRGINIC} = \boldsymbol{\mu}_{VERSICOL}$ (não há diferença)
- $H_1$: pelo menos um par de espécies tem vetores de médias diferentes

Nível de significância: $\alpha = 0{,}05$.

#+begin_src python :session ex1 :results output :exports both
from statsmodels.multivariate.manova import MANOVA

formula = 'SEPALLEN + SEPALWID + PETALLEN + PETALWID ~ specie'
manova  = MANOVA.from_formula(formula, data=df_iris)
result  = manova.mv_test()
print(result)
#+end_src

*** Interpretação

#+begin_src python :session ex1 :results output :exports both
stat_table = result.results['specie']['stat']
wilks = float(stat_table.loc["Wilks' lambda", "Value"])
f_val = float(stat_table.loc["Wilks' lambda", "F Value"])
p_val = float(stat_table.loc["Wilks' lambda", "Pr > F"])

print(f"Estatística de Wilks' Lambda : {wilks:.6f}")
print(f"F-estatístico                : {f_val:.4f}")
print(f"p-valor                      : {p_val:.2e}")
print()
if p_val < 0.05:
    print("Decisão: REJEITA-SE H₀  (p < 0,05)")
    print("→ Existe diferença estatisticamente significativa entre as espécies")
    print("  nas variáveis morfométricas (SEPALLEN, SEPALWID, PETALLEN, PETALWID).")
else:
    print("Decisão: NÃO se rejeita H₀  (p ≥ 0,05)")
    print("→ Não há evidência de diferença significativa entre as espécies.")
#+end_src
